# Phantom Inventory Alert Intelligence

## Overview:
    This interactive Phantom Inventory Alert Intelligence Dashboard provides insights into alerts generated information, corresponding response details, sales recovery calculations, ROI details. It also integrates an AI Chatbot assistant to get answers for dashboard & business related queries.

## KPIs:
    Alerts Sent -- Total Alerts generated
    Responses Received -- Vendor responses received
    Response Rate -- Responses Received/Alerts Sent
    Correct Alerts -- Alerts confirmed as correct PI,SOA, or OOS alert
    Accuracy % -- Correct Alerts/Responses Received
    Actioned Alerts -- Alerts where corrective action was taken
    Resolved Alerts -- Alerts successfully closed
    Resolution % -- Resolved/Correct Alerts
    Recovered Sales -- (Post issue resoltuion sales - Pre issue resolution sales)
    Sales Lift -- Post issue resoltuion sales/Pre issue resolution sales
    ROI -- Return generated by alerting (Recovered Sales/Cost), where Cost is (Vendor Responses * Vendor cost per alert)
    Dollar per Alert -- Average recovered sales generated per resolved alerts (Recovered Sales/Resolved Alerts)
